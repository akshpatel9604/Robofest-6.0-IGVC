# YOLOv8n detection

This folder is for object detection on Raspberry Pi 5.

## Model
- Algorithm: YOLOv8n / YOLO11n
- Runtime: ONNX / NCNN
- Camera: Raspberry Pi Camera Module 3

## Contest classes
- cone
- box
- stop
- left
- right
- traffic light
- parking mark
- grasp object

QR / AprilTag will be read with OpenCV, not YOLO.
